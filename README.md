# Time-Series Forecasting
This repository is unofficial implementation of following papers with PyTorch. The corresponding folder name is written in parenthesis.

## General Methods
- [DistDF: Time-Series Forecasting Needs Joint-Distribution Wasserstein Alignment](https://openreview.net/forum?id=VrdLwUmzBy) (`DistDF`)

## Stock Price Prediction
- [StockMixer: A Simple Yet Strong MLP-Based Architecture for Stock Price Forecasting](https://ojs.aaai.org/index.php/AAAI/article/download/28681/29322) (`StockMixer`)
- [Efficient Integration of Multi-Order Dynamics and Internal Dynamics in Stock Movement Prediction](https://dl.acm.org/doi/10.1145/3539597.3570427) (`ESTIMATE`)
- [Dynamic Higher-Order Relations and Event-Driven Temporal Modeling for Stock Price Forecasting](https://www.ijcai.org/proceedings/2025/673) (`SPF-IJCAI25`)
- [DYCOR: Capturing Hidden Stock Relationships for Stock Trend Prediction](https://dl.acm.org/doi/10.1145/3746252.3761413) (`DYCOR`)
